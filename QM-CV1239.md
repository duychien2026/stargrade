## User-requested fresh start, 2026-11-02

Under an exclusive lock it first saves the entire original JSON in a private `storage/data.json.fresh-start-20261102-qmcv1239.<random>.bak` file (owner read/write only), then clears exams, keys, students and submissions, including their embedded images. A completed migration never clears newly created exams on later requests or deployments.

The migration is part of bootstrap so the same request applies consistently to local, Render and shared hosting stores. No reset endpoint is exposed. `php tests/fresh-start.php` verifies the complete backup, account preservation, empty exam data and idempotence. To recover, an administrator can stop writes and restore the named backup; re-add the completed migration marker before resuming requests, or it will intentionally apply again.
